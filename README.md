# Carpet Dan Addition

A Carpet addon for Minecraft 26.3+. All rules are in the `dan` category.

English | [简体中文](README_zh.md)

## Requirements

- Minecraft 26.3
- Fabric Loader 0.19.5 or newer
- Fabric Carpet 26.3 or newer
- Java 25

## Documentation

See the [Wiki](wiki/Rules.md) for the full rule list, metadata and examples.

| Rule | Summary |
| --- | --- |
| [TNTchunkloading](wiki/Rules.md#tntchunkloading) | Keeps fast-moving primed TNT chunk-loaded. |
| [fishingTreasureNoOpenWater](wiki/Rules.md#fishingtreasurenoopenwater) | Removes the open water requirement for fishing treasure, or makes fishing treasure-only. |
| [hoebedrockbreaking](wiki/Rules.md#hoebedrockbreaking) | Lets a hoe break bedrock. |
| [crispydeepslate](wiki/Rules.md#crispydeepslate) | Mines deepslate at stone speed. |
| [TNTdrag](wiki/Rules.md#tntdrag) | Chooses the air drag precision applied to primed TNT. |
| [mergeTNTdebug](wiki/Rules.md#mergetntdebug) | Adds `/mergeTNT` for spawning TNT with a chosen explosion count. |
| [botnoclip](wiki/Rules.md#botnoclip) | Stops entities from pushing Carpet fake players. |
| [botToolSwap](wiki/Rules.md#bottoolswap) | Makes fake players switch to better tools and replace worn ones. |
| [botmemo](wiki/Rules.md#botmemo) | Adds `/botmemo` to save and restore fake player state. |
| [botChineseName](wiki/Rules.md#botchinesename) | Allows quoted Unicode names in `/player`. |
| [deathchest](wiki/Rules.md#deathchest) | Stores a dead player's items in chests at the death spot. |
| [leashableVillagers](wiki/Rules.md#leashablevillagers) | Lets villagers and wandering traders be leashed. |
| [villagerneverstoptrading](wiki/Rules.md#villagerneverstoptrading) | Freezes trade uses so offers never lock. |
| [noBatSpawning](wiki/Rules.md#nobatspawning) | Stops natural bat spawning. |
| [noAquaticSpawning](wiki/Rules.md#noaquaticspawning) | Stops natural aquatic mob spawning. |
