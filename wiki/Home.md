# Carpet Dan Addition Wiki

English | [简体中文](Home_zh.md)

Carpet Dan Addition is a Carpet addon for Minecraft 26.3+. Every rule is in the `dan` category.

## Installation

- Minecraft 26.3
- Fabric Loader 0.19.5 or newer
- Fabric Carpet 26.3 or newer
- Java 25

Put the jar in `mods/`. The rules run on the server. Installing the mod on the client is optional; it is only needed for quoted Unicode name suggestions in `/player` and `/tp`.
