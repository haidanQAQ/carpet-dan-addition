# Carpet Dan Addition

一个面向 Minecraft 26.3+ 的 Carpet 拓展。所有规则都在 `dan` 分类下。

[English](README.md) | 简体中文

## 依赖

- Minecraft 26.3
- Fabric Loader 0.19.5 或更新
- Fabric Carpet 26.3 或更新
- Java 25

## 文档

完整的规则列表、元数据和示例见 [Wiki](wiki/Rules_zh.md)。

| 规则 | 作用 |
| --- | --- |
| [TNTchunkloading](wiki/Rules_zh.md#tntchunkloading) | 让高速移动的点燃 TNT 保持区块加载。 |
| [fishingTreasureNoOpenWater](wiki/Rules_zh.md#fishingtreasurenoopenwater) | 取消钓鱼宝藏的开放水域要求，或让钓鱼只出宝藏。 |
| [hoebedrockbreaking](wiki/Rules_zh.md#hoebedrockbreaking) | 允许用锄头破坏基岩。 |
| [crispydeepslate](wiki/Rules_zh.md#crispydeepslate) | 让深板岩按石头速度挖掘。 |
| [TNTdrag](wiki/Rules_zh.md#tntdrag) | 选择点燃 TNT 的空气阻尼精度。 |
| [mergeTNTdebug](wiki/Rules_zh.md#mergetntdebug) | 增加 `/mergeTNT`，生成指定爆炸次数的 TNT。 |
| [botnoclip](wiki/Rules_zh.md#botnoclip) | 让任何实体都推不动 Carpet 假人。 |
| [botToolSwap](wiki/Rules_zh.md#bottoolswap) | 假人自动换更好的工具，并替换快坏的工具。 |
| [botmemo](wiki/Rules_zh.md#botmemo) | 增加 `/botmemo`，保存和恢复假人状态。 |
| [botChineseName](wiki/Rules_zh.md#botchinesename) | 允许 `/player` 使用带引号的中文名。 |
| [deathchest](wiki/Rules_zh.md#deathchest) | 死亡后把物品装进死亡点的箱子。 |
| [leashableVillagers](wiki/Rules_zh.md#leashablevillagers) | 村民和流浪商人可以被拴绳拴住。 |
| [villagerneverstoptrading](wiki/Rules_zh.md#villagerneverstoptrading) | 冻结交易已用次数，交易永不锁定。 |
| [noBatSpawning](wiki/Rules_zh.md#nobatspawning) | 禁止蝙蝠自然生成。 |
| [noAquaticSpawning](wiki/Rules_zh.md#noaquaticspawning) | 禁止水生生物自然生成。 |
